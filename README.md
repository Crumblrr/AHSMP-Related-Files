# All Related Arthouse SMP Files
This is for all files related to Arthouse SMP, especially Figura. This repository will include a download for AHSMP1 and for the AHSMP1 modpack, as well as downloads for the AHSMP2 modpack, however this is mostly here to share things for Figura.

The main goal of this is to compile files related to Figura to give Arthouse members an easy time accessing them. I have not personally created everything uploaded here.
This will include scripts and models. For the most part, these scripts and models will have been created by other authors. Full credit goes to them and will be included within those files.
Please do not share this outside of Arthouse. I do not wish to take away from the original authors of anything, this is purely to make it easier for my friends to locate these files.



Links to OG authors githubs (if provided / if they exist) will be linked below.
A couple of the scripts provided here have been edited by my Dad (thank you Dad!). These include:
- physBonesAPI (heavily modified, please do not report any issues you encounter to the original script authors, they will not be able to help you and will not be the ones who caused that issue)
- EZAnims (minor addition to the script. if you encounter any issues, it is more likely to be something related to the original script, as nothing about it has been modified, only added)
