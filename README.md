# Arthouse-Figura-Help
This is to compile files related to Figura to give Arthouse members an easy time accessing them. I did not personally create everything uploaded here.

This will include scripts and models. For the most part, these scripts and models will have been created by other authors. Full credit goes to them and will be included within those files.
Please do not share this outside of Arthouse. I do not wish to take away from the original authors of anything, this is purely to make it easier for my friends to locate these files.
